# Security policy

This repository contains a reference implementation and synthetic fixtures. It
must not receive real credentials, machine inventories, private project data,
customer data, employer-owned material, or restricted personal records.

Report a suspected secret or disclosure issue privately to the repository
owner. Do not open a public issue containing the material. Remove the content
from the working tree, rotate any exposed credential at its authoritative
provider, and rebuild affected history only through an explicitly reviewed
recovery plan.

Repository privacy is access control, not proof that content is safe to
publish. A human review of the full diff remains required even when automated
scanning passes.
